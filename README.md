# Сайт агента по недвижимости

Одностраничный сайт Людмилы Тихоновой, агента по новостройкам
Санкт-Петербурга и Ленинградской области.

## Что внутри

Один файл `index.html`. Всё содержимое, включая изображения, стили
и скрипты, лежит внутри него. Внешних зависимостей нет, сборка не нужна,
папки с картинками рядом не требуется.

Открывается двойным кликом или заливается на любой хостинг как есть.

## Разделы

- Первый экран с портретом и подсветкой фасада на canvas
- Цифры: стаж, диапазон бюджетов, география, результат по инвестиционному кейсу
- Обо мне
- Услуги: подбор для жизни, инвестиции, ипотека нестандартным заемщикам,
  меблировка с поиском арендатора, загородная недвижимость
- Галерея объектов
- Ипотечные программы и схемы оплаты
- Кейсы
- Отзывы клиентов с оригиналами переписок
- Порядок работы в пяти шагах
- Чеклист проверки застройщика
- Квиз подбора на три вопроса
- Контакты

## Технически

- Чистый HTML, CSS и JavaScript без фреймворков
- Шрифты Prata, Golos Text и JetBrains Mono с Google Fonts,
  для каждого прописан запасной системный шрифт
- Адаптив от 360 пикселей
- Анимации отключаются при системной настройке «уменьшить движение»
- Изображения встроены как data URI, портрет первого экрана в формате WebP

## Что доделать перед публикацией
