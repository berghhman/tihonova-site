# Сайт Людмилы Тихоновой

Одностраничный сайт агента по новостройкам Санкт-Петербурга.
Каждая версия - один самодостаточный HTML-файл: стили, скрипты и изображения
в base64 внутри документа. Сборка не нужна, достаточно открыть файл в браузере.

## Версии

| Файл | Версия | Описание |
|---|---|---|
| `index.html` | 3 / структура | Текущая. Акцент на визуал и структуру рынка: география, классы жилья, путь сделки, схемы оплаты. Минимум текста. |
| `v2-kino.html` | 2 / кино | Полноэкранные сцены, скролл-анимации, манифест с подсветкой слов. |
| `v1-kratkaya.html` | 1 / классика | Первая версия с развернутыми текстами и скриншотами отзывов. |

## Что внутри текущей версии

- Полноэкранный первый экран с параллаксом и вырезанной фигурой
- Счетчики цифр
- Сетка из шести регионов подбора
- Матрица классов жилья: конструктив, паркинг, двор
- Шкала сделки из семи шагов с анимацией заливки
- Лента ипотечных программ, едет по горизонтали на вертикальном скролле
- Сетка проверки застройщика
- Пять направлений работы со сменой фотографии при скролле
- Три кейса на полный экран
- Квиз на три вопроса с текстовым выводом
- Живое зерно пленки на канвасе, виньетка, рейка глав и полоса прогресса
- Поддержка prefers-reduced-motion

## Техническое

- Шрифты: Oswald, Golos Text, JetBrains Mono (Google Fonts)
- Изображения: WebP в base64, кинематографическая цветокоррекция
- Внешних зависимостей, кроме шрифтов, нет
- Ширины проверены на 1440, 1024, 390 и 360
